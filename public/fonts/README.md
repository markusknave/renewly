# Bundled fonts

Renewly bundles WOFF2 subsets from Google Fonts so themes work offline. The
families are licensed under the SIL Open Font License 1.1.

| Family | Source |
| --- | --- |
| Poppins | https://fonts.google.com/specimen/Poppins |
| Inter | https://fonts.google.com/specimen/Inter |
| Roboto | https://fonts.google.com/specimen/Roboto |
| Open Sans | https://fonts.google.com/specimen/Open+Sans |
| Montserrat | https://fonts.google.com/specimen/Montserrat |
| Lato | https://fonts.google.com/specimen/Lato |
| Nunito Sans | https://fonts.google.com/specimen/Nunito+Sans |
| DM Sans | https://fonts.google.com/specimen/DM+Sans |
| Work Sans | https://fonts.google.com/specimen/Work+Sans |
| Manrope | https://fonts.google.com/specimen/Manrope |

The files are latin subsets served by the Google Fonts CSS API for the weights
used by the interface. Copyright and license terms remain with each family's
authors. The SIL Open Font License is available at:

https://openfontlicense.org/open-font-license-official-text/

Do not remove this notice when redistributing the bundled fonts.
